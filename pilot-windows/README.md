# Пилот на своём компьютере (Windows)

1. Скачайте папку `pilot-windows` (или весь репозиторий: Code → Download ZIP) и распакуйте.
2. Зарегистрируйтесь на https://tuna.am, в кабинете скопируйте токен (главная страница кабинета) и постоянный адрес из раздела «Домены» (вида `snowy-orca-6775.a.tuna.free`).
3. Запустите `start-pilot.bat`. В первый раз он спросит токен и домен, поставит Python (если нет), создаст входы `dp1`, `dm11472`, `sales`, `region` и откроет файл с паролями.
4. В окне появится ссылка для участников — она уже скопирована. Откройте её на каждом телефоне один раз.

Пока окно открыто, сервер работает, а компьютер не засыпает. Данные и фото — в `%USERPROFILE%\audit-sibir-pilot\data`, при перезапуске сохраняются. При каждом запуске подтягивается свежая версия приложения с GitHub.
